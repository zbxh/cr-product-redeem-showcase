# 产品兑换码使用指南

适用于 **0.1.0 预览版**。安装包可通过开发者获取。

## 1. 安装与检查

1. 启用 V10 官方续费插件。将包内的 `cr_product_redeem` 放入 `public/plugins/addon/`，在后台应用列表安装。
2. 打开「产品兑换码 → 基础设置」，检查权限、兼容情况和客户入口。新安装默认关闭客户新兑换。
3. 给负责配置、生成、明码查看、导出和作废的角色分配所需权限。登记非零的站外已收款金额时，先启用 V10 线下支付网关。

## 2. 新建方案并发码

1. 打开「兑换方案 → 新建方案」，选择商品并进入原生配置界面。选择资源、系统和首期周期后点击「读取所选配置与首期周期」。
2. 设置方案名称、客户可选项、首期订单金额和开放的续费周期。为每个续费周期设定独立固定金额或正常商品价格，并指定自动续费默认周期。
3. 从方案创建批次，配置有效期、客户范围、每人次数及生成数量。生成后规则以批次为准。把兑换码交付给对应客户。
4. 通过测试会员核对兑换、订单和开通，再按需开放客户新兑换。

[兑换方案](images/admin-scheme.png) · [发码批次](images/admin-batch.png)

## 3. 客户兑换与后台核对

客户登录后输入兑换码，通过预览核对固定资源、订单金额与续费规则，选择开放的系统和登录配置，再确认兑换。在「我的兑换记录」可查看状态、原生订单和产品。

后台可按商品、批次、客户或结果查询。「暂停批次」和「作废」适用于仍可使用的兑换码，已提交的兑换继续按原记录处理。首期有站外收款时，退款由原购买渠道处理。
